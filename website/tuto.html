Écouter la traduction en quatre gestes

Pas d’application, pas de compte. Il vous faut un téléphone, une connexion (4G ou Wi-Fi) et des écouteurs.

Les étapes

  1. Branchez vos écouteurs

    Filaires ou Bluetooth. L’écoute se fait uniquement aux écouteurs, pour ne pas gêner vos voisins.

  2. Scannez le QR code

    Il est projeté à l’écran ou affiché à l’accueil. Ouvrez l’appareil photo, visez le code, puis touchez le lien qui apparaît.

  3. Touchez votre langue

    La page affiche les langues traduites aujourd’hui. Si le message n’a pas encore commencé, choisissez quand même : le son arrivera tout seul.

  4. Écoutez, écran verrouillé si vous voulez

    Le son continue quand le téléphone est verrouillé. Les sous-titres s’affichent si vous gardez la page ouverte.

Si vous n’entendez rien

Touchez l’écran une fois
Certains téléphones attendent un geste avant de jouer le son. Le message « Touchez l’écran pour lancer le son » s’affiche dans ce cas.
Vérifiez le volume
Montez le volume du téléphone avec ses boutons, puis le curseur de la page.
La traduction n’a pas commencé
Un message l’indique sur la page. Gardez-la ouverte : le son arrive dès que la régie lance la traduction.
Toujours rien
Rechargez la page, puis touchez à nouveau votre langue. Si le réseau coupe, la page se reconnecte seule.

Prêt ?

Branchez vos écouteurs et ouvrez la page d’écoute.
